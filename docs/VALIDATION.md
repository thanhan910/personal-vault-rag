# Validation

`scripts/vaultctl verify` checks Compose configuration, API/Qdrant health, automated vault/security/catalogue/extraction tests, Go connector tests, package manifests and Windows checksums. The focused repair regressions cover provider backfill/readiness, per-attempt budget enforcement, provider-reported text/multimodal usage, visual-only extraction, locator-safe visual evidence, current/history behavior, cross-channel filter defense, preview recovery, binary-plus-note handoff, collision safety, saved-folder registration and daemon pause reload.

`scripts/evaluate.py` generates a disposable English/Vietnamese corpus with exact IDs, paraphrasable facts, conflicting dates, a multi-document programme, XLSX cells, DOCX, PPTX, a scanned image/PDF, synthesized speech and a short video. It ingests through the real HTTP/worker path and requires both sides of conflict and multi-document checks, complete citation identities/locators, an explicit caution for unsupported semantic-only matches, and bounded spreadsheet arithmetic.

Keep live measurements in [PROGRESS.md](PROGRESS.md). Passing this small synthetic corpus proves exercised paths, not universal accuracy, tens-of-thousands scale, Windows runtime behavior or paid-provider quality. Linux tests exercise portable connector logic and compile the test suite and production binary for Windows; they do not execute the Windows binary. DPAPI, folder picking, Task Scheduler, cloud hydration, Claude UI installation, ChatGPT account OAuth and subscription-model answers require their actual clients and must be reported separately.
