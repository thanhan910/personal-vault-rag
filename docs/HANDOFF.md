# Handoff

The backend, worker, vector store, private UI, OAuth/MCP surface and Windows packages are reproducible from this repository. Start at [the operator guide](HOWTO-HUMAN.md); recover with [restart](RESTART.md) and [backup/restore](BACKUP-RESTORE.md).

Do not declare remote consumer integration complete until the operator finishes account sign-in and an actual tool call succeeds in that client. Do not claim Windows validation from Linux cross-compilation. Provider-backed semantic and visual evaluation stays pending until a user enters their own key and allowance locally; lexical operation must remain truthful without it.

Before future changes read root `AGENTS.md`, preserve vault scoping, back up relevant data/configuration, run unit tests plus the synthetic evaluation, validate host ingress, inspect resource pressure, update documentation, and commit/push under workspace policy.
